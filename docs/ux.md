# UX-концепция

## Персоны

### Персона 1: Организатор совместной покупки

- Цели: быстро создать заказ, добавить участников, посчитать расходы.
- Важно в первые 30 секунд: увидеть список активных заказов и статус оплат.

### Персона 2: Участник заказа

- Цели: понять, что он заказал и сколько должен оплатить.
- Важно в первые 30 секунд: увидеть свою сумму и статус оплаты.

## User Stories

1. Как организатор, хочу создать совместную покупку, чтобы собрать общий заказ для нескольких людей.
  - Шаги: открыть список заказов, нажать "Создать", заполнить форму, сохранить.
  - Done-критерий: заказ появляется в списке.
  - 

2. Как организатор, хочу добавить позиции заказа, чтобы рассчитать стоимость для участников.
  - Шаги: открыть заказ, добавить позицию, выбрать участника, указать цену и количество.
  - Done-критерий: позиция появляется в таблице заказа.

3. Как организатор, хочу отмечать оплаты, чтобы понимать, кто уже оплатил свою часть.
  - Шаги: открыть заказ, посмотреть список участников, изменить статус оплаты.
  - Done-критерий: статус оплаты обновляется.

## Дизайн-система Taiga UI 4

- Используемые компоненты: Button, Input, Textarea, Select, Table, Badge, Dialog, Notification.
- Кастомные компоненты: карточка заказа, таблица позиций, блок расчёта расходов, статус оплаты.

## Приоритеты

- Первый экран: список активных совместных покупок.
- Вторично: история завершённых заказов и рейтинг участников.
- Сознательно убрано из MVP: реальные приглашения по email и онлайн-оплата.
