# План разработки

## Цель проекта

Цель проекта — разработать Angular-приложение для организации совместных покупок. Приложение помогает организатору создавать групповые заказы, добавлять участников, фиксировать позиции заказа, рассчитывать долю каждого участника и отслеживать оплаты.

## Пользовательские сценарии

1. Организатор входит в систему и видит список своих совместных покупок.
2. Организатор создаёт новую совместную покупку с названием, описанием и условиями.
3. Организатор добавляет участников и позиции заказа.
4. Приложение рассчитывает сумму для каждого участника и показывает статус оплаты.


## Риски

1. Сложность авторизации — использовать mock-login и хранить токен в localStorage.
2. Нехватка времени на тесты — заранее выделить сервисы расчётов и авторизации для unit-тестов.
3. Сложность state management — использовать Signal Store как более простой вариант.
